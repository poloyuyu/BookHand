## 11. Probabilidad

### 11.1 Esperanza, varianza y desigualdades

- $𝔼[X] = ∑_x x Pr(X=x)$.
- **Linealidad:** $𝔼[X+Y] = 𝔼[X]+𝔼[Y]$ siempre.
- Independencia: $𝔼[XY] = 𝔼[X]𝔼[Y]$.
- Varianza: $Var(X) = 𝔼[X^2]-𝔼[X]^2$; $Var(aX+b) = a^2 Var(X)$; $Var(X+Y) = Var X + Var Y$ si indep.
- **Desigualdades:** Markov $Pr(X ≥ a) ≤ 𝔼[X]/a$; Chebyshev $Pr(|X-μ| ≥ kσ) ≤ 1/k^2$.
